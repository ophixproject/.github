# Security Policy

If you believe you've found a security vulnerability in an Ophix package, please report it privately rather than opening a public issue — a public report could expose users before a fix is available.

**Contact:** security@ophix.io

Please include:
- The affected package and version
- A description of the vulnerability and its impact
- Steps to reproduce, if possible

We'll acknowledge your report and work with you on a fix and coordinated disclosure timeline.
